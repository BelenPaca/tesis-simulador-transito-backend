# Leyes Oficiales para GitOps RAG

Coloca aquí los archivos de leyes limpias en formato Markdown (`.md`) o texto (`.txt`).
Cada archivo representa un cuerpo legal oficial (ej. `coip_transito.md`, `cogep.md`, `lotttsv.md`, etc.).

El pipeline de GitHub Actions calculará el hash SHA-256 de cada archivo y lo sincronizará automáticamente con Qdrant Cloud y Neon PostgreSQL.
